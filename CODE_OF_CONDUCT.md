# Community conduct

This project welcomes useful questions, careful bug reports and constructive
disagreement. Treat contributors and users with respect, regardless of their
background, identity, experience or technical ability.

Keep feedback about the work. Explain problems with reproducible facts, give
others room to correct mistakes, and respect decisions about project scope.
Harassment, threats, discriminatory language, personal attacks, impersonation,
spam and disclosure of another person's private information are not acceptable.
Never post credentials, private conversations or runtime databases.

These expectations apply in repository issues, pull requests and other project
spaces moderated by its maintainers. Maintainers may edit or remove harmful
content, limit participation, or block repeat or serious abuse. Responses should
be proportionate to the behavior and protect affected people. Maintainers are
held to the same standard.

Use GitHub's reporting tools for abusive content or users. For a concern that
requires confidential maintainer review, use a private channel already agreed
with the maintainer; do not publish personal allegations or contact details in
an issue. The [maintainer profile](https://github.com/onehumanbeing) identifies
the project owner but is not a promise of a private messaging service.

Security vulnerabilities follow [SECURITY.md](SECURITY.md), not public issue
discussion. Ordinary product questions and reproducible bugs follow
[SUPPORT.md](SUPPORT.md).
